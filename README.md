# AI Чат · Android

Тестовое приложение: **Kotlin, Jetpack Compose, Coroutines/Flow, Room**. Реальные ответы OpenRouter через Cloudflare HTTPS. Mac и общая Wi-Fi сеть не нужны.

## Что проверяют — ответы по порядку

### 1. Пустой чат

**Токен по device_id, 3 бесплатных сообщения, блокировка пустой отправки?**
Да. Хеш ANDROID_ID → access/refresh; токены зашифрованы Android Keystore. Сервер сохраняет лимит после обновления и переустановки APK с той же подписью. При обновлении старый UUID привязывается к устройству без сброса остатка. Пустой и пробельный ввод не отправляется.

Ограничения: другой профиль Android, подпись APK или сброс устройства меняют ID; это защита от обычной переустановки, а не полноценный антифрод. Если старую версию удалить до обновления с привязкой, сопоставить её UUID с устройством невозможно. При недоступном ANDROID_ID используется ID установки.

### 2. Стриминг

**SSE, Markdown, «Стоп», refresh посреди ответа без потери текста?**
Да. Фрагменты и event ID сохраняются в Room. После refresh продолжается та же генерация; Mutex исключает параллельные обновления токена. «Стоп» сохраняет частичный текст. Печатание — по одному символу с курсором.

### 3. Ошибка сети

**Часть ответа сохраняется, есть «Повторить», нет бесконечных ретраев и разлогина?**
Да. При обрыве — до двух переподключений через 1 и 3 секунды с сохранённого event ID, затем ручной «Повторить». Если сам AI завершился ошибкой, повтор создаёт новый ответ, сохранив старый фрагмент. Ошибка, пустой ответ и отмена возвращают резерв бесплатного сообщения. Повторы ограничены; есть резервная модель и ключ.

### 4. Список чатов

**Room, сохранение после перезапуска, даты, поиск, название из первого сообщения?**
Да. История локальная, группы «Сегодня / Вчера / Ранее», поиск по названию. Заголовок — первые 55 символов первого сообщения. Добавлено удаление с подтверждением.

### 5. Пейвол

**После лимита, проверка подписки при старте, восстановление, цены из стора?**
Пейвол открывается после последнего успешного ответа и завершения печатания. Billing запрашивает покупки и ProductDetails; есть «Восстановить покупки» и серверная проверка чека.

**Ограничение:** Play Console пока не настроена — настоящие цены, покупка и успешное восстановление не проверены. По согласованию добавлены **тестовые цены 499 ₽ / 1 290 ₽**, если магазин не вернул тарифы. Они помечены; оплата по ним отключена. Фиктивного PRO-доступа нет.

## Сервисы и библиотеки

| Что | Зачем |
|---|---|
| Kotlin + Jetpack Compose / Material 3 | Экраны, состояния и анимации |
| Coroutines / Flow + ViewModel | Асинхронная работа и обновление UI |
| Room + KSP | Локальная история и сохранение фрагментов ответа |
| OkHttp | HTTPS-запросы и чтение SSE |
| Markwon | Отображение Markdown |
| Android Keystore | Шифрование токенов на устройстве |
| Google Play Billing | Тарифы, подписка и восстановление покупок |
| OpenRouter | Настоящие AI-ответы, резервные бесплатная модель и ключ |
| Cloudflare Workers + SQLite Durable Objects | API, авторизация, лимиты и продолжение SSE |
| Node.js | Альтернативный локальный backend |
| JUnit, MockWebServer, Compose Test, Miniflare | Проверка приложения, сети и облачного backend |

Секреты хранятся только в конфигурации сервера / Cloudflare Secrets. В репозитории и APK ключей нет.

## Карта проекта

```text
app/src/main/java/dev/test/aichat/
├── MainActivity.kt          Вход в приложение
├── ChatApplication.kt       Зависимости
├── ui/                      Экраны Compose, тема, ChatViewModel
├── data/                    Room, ChatRepository, сохранение SSE
├── network/                 API, SSE parser, Auth, Keystore
└── billing/                 Google Play Billing
app/src/test/                JVM: SSE и авторизация
app/src/androidTest/         Room, UI, клавиатура, живые сценарии
cloud/                       Worker + SQLite Durable Objects, облачные тесты
server/                      Локальный backend, общий prompt и fallback
scripts/                     Запуск локального сервера
```

Поток данных: `Compose → ViewModel → Repository → API / Room → StateFlow → UI`.

## Запуск

JDK 17/21 и Android SDK 36; облачный адрес уже настроен.

```sh
./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Ключей в APK и Git нет. Настройка своего backend и магазина: [setup.md](docs/setup.md), [Cloudflare](docs/cloud.md).
