# Облачный backend

Адрес backend: https://ai-chat-android-test.vladius-apps-bd9433.workers.dev/

Cloudflare Worker `ai-chat-android-test`, SQLite Durable Objects `DeviceChat` и `PurchaseOwner`. Телефону нужен интернет; Mac и общая Wi-Fi сеть не нужны. Приложение не содержит ключ OpenRouter. Он загружен в Cloudflare Secret.

## Развёртывание собственного экземпляра

Нужны Node.js 22+, Cloudflare account и ключ OpenRouter. Из `cloud/`:

```sh
npm ci
npx wrangler login
npx wrangler deploy
npx wrangler secret put OPENROUTER_API_KEY
```

Последняя команда читает ключ интерактивно; не передавайте его аргументом командной строки. Для цен и настоящих покупок нужна отдельная настройка Play Console из README. JSON сервисного аккаунта Google хранится только в секрете `GOOGLE_SERVICE_ACCOUNT_JSON`. При изменении package ID задайте согласованный `ANDROID_PACKAGE` на backend.

Использованы возможности Workers/SQLite Durable Objects, доступные на бесплатном плане. Платный план в рамках задачи не подключался; квоты платформы и бесплатных AI-моделей действуют. Это не обещание неограниченного бесплатного сервиса.

## Хранение и ограничения

- Каждый device_id маршрутизируется в собственный SQLite Durable Object. Токены проверяются по хешам; префикс маршрутизации сам по себе не даёт доступ.
- Лимит, резервирование запроса и терминальные события записываются атомарно. Ошибка, пустой результат и отмена возвращают резерв ровно один раз. Успешный ответ расходует одно сообщение.
- События SSE сохраняются на сервере; клиент сохраняет event ID и текст в Room. Refresh/потеря связи не требуют заново генерировать текст.
- Завершённые события переживают пересоздание объекта. Если выполнявшаяся генерация потеряна при пересоздании, сохранённый фрагмент остаётся, запрос завершается ошибкой и резерв возвращается. Вычисление у провайдера возобновить нельзя.
- Завершённые генерации старше часа удаляются при активности. Максимум две параллельные генерации на устройство, три ручных повтора после терминальной ошибки, 180 секунд на ответ, 120 тысяч символов вывода, 100 КБ входящего JSON. Получение новых токенов ограничено по IP.
- OpenRouter получает две бесплатные модели и `max_price` 0. Переход на резервную модель выполняется OpenRouter; после частичного терминального сбоя автоматическая подмена ответа не производится.
- device_id — хеш ANDROID_ID: обычная переустановка APK с той же подписью не сбрасывает лимит. Старая сессия привязывается через проверенный refresh token; другая подпись/профиль Android/сброс устройства меняют ID. Это не полноценный антифрод.

## Проверки

Из `cloud/`:

```sh
npx tsc --noEmit
WRANGLER_SEND_METRICS=false npx wrangler deploy --dry-run --outdir dist
node --test cloud.test.mjs
```

Девять тестов Miniflare используют изолированный тестовый upstream: квота/идемпотентность/пейвол, возврат после ошибки, SSE resume, refresh посреди SSE, stop/изоляция устройств, восстановление событий после перезапуска, два сценария миграции device_id и однократный сброс квоты. Тестовый upstream не включён в развёрнутый Worker.

Живой Android-прогон использует реальный OpenRouter и не сбрасывает квоту:

```sh
adb shell am instrument -w -e liveCloud true -e class dev.test.aichat.LiveCloudAcceptanceTest dev.test.aichat.test/androidx.test.runner.AndroidJUnitRunner
```

Тест требует 1–3 оставшихся сообщения на текущей установке. Повторный запуск после исчерпания квоты намеренно не обходит ограничение.

## Резервный ключ

`OPENROUTER_API_KEY_BACKUP` — отдельный Cloudflare Secret. Подключён и проверен запросом `/api/v1/key`. Переключение выполняется максимум один раз, до начала SSE, при HTTP 401, 429 или 402 с `limit_source=openrouter_key_limit`. Баланс аккаунта и ошибки уже открытого стрима не запускают перебор ключей. `Retry-After` до 3 секунд выдерживается перед резервной попыткой; при более долгом ожидании запрос завершается ошибкой без автоматического повтора. Пользователь подтвердил, что резервный ключ относится к другому аккаунту. В этих случаях показывается ошибка и возвращается резерв бесплатного сообщения после терминального сбоя. Дополнительные ключи не увеличивают общие лимиты OpenRouter: https://openrouter.ai/docs/api_reference/limits .

Проверки общей реализации резервного ключа: `node --test server/provider.test.mjs` (6 тестов). Вместе с локальным backend — 14/14; Cloudflare — 9/9.

## Однократный административный сброс лимитов

Оператор может задать новое уникальное значение секрета `QUOTA_RESET_EPOCH`. При следующем обращении каждый аккаунт один раз получает лимит 3 с учётом активных резервов. Повторный вход и перезапуск не повторяют сброс. История, сессии и подписки сохраняются. Публичного API сброса и кнопки в приложении нет.
