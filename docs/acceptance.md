# Проверка и видео

APK по умолчанию подключается к облачному backend с серверным ключом OpenRouter. Mac запускать не нужно. Демоответов и переключателей для поддельного успеха нет.

1. Открыть приложение после установки. Завершить онбординг. Убедиться, что сервер выдал токены, видны 3 сообщения, пустую строку и пробелы нельзя отправить.
2. Отправить вопрос с просьбой дать ответ с заголовками и списками. Проверить реальное постепенное поступление текста и Markdown. Нажать «Стоп» во время длинного ответа — текст остаётся.
3. Для проверки refresh можно временно установить реальный короткий срок токена `ACCESS_TTL_SECONDS=10` и перезапустить backend. Во время ответа длиннее 10 секунд обновление должно пройти без дублей. Это настройка срока действия авторизации, не режим имитации. Вернуть стандартные 60 секунд после проверки.
4. Прервать сеть во время другого ответа. Дождаться ошибки (HTTP timeout не больше 35 секунд без heartbeat). Убедиться, что текст остаётся. Восстановить сеть и нажать «Повторить»: продолжение той же генерации, без повторного списания. Если провайдер сам окончательно завершился с ошибкой, повтор создаёт отдельный ответ и сохраняет предыдущий фрагмент.
5. Открыть список, найти чат по названию, открыть его. Перезапустить процесс приложения и повторно убедиться в наличии истории.
6. Израсходовать лимит успешными ответами. После последнего ответа пейвол должен открыться автоматически. Отмена или терминальная ошибка должны вернуть бесплатное сообщение и не открывать пейвол. Для живых цен и восстановления нужны подписки и тестовый трек Google Play из README. При отсутствии продуктов магазина показываются согласованные тестовые цены 499 ₽ / 1 290 ₽ с явной подписью. «Продолжить» недоступна, успешная покупка не подделывается. «Восстановить покупки» остаётся настоящим запросом к Play.

## Видео

Короткая запись на 1–2 минуты: пустой чат → реальный стрим → стоп → список и поиск → перезапуск и история → пейвол. Отдельный фрагмент по возможности показывает потерю сети и refresh.

```sh
adb shell screenrecord --time-limit 120 /sdcard/ai-chat-walkthrough.mp4
adb pull /sdcard/ai-chat-walkthrough.mp4 docs/ai-chat-walkthrough.mp4
```

Запись без ключа показывает только интерфейс/ошибку настройки и не заменяет видео работающего AI. Не включать API-ключи, JSON сервисного аккаунта и токены в запись или логи.

7. В списке чатов нажать корзину: «Отмена» оставляет чат; «Удалить» удаляет его вместе с сообщениями. Проверить после пересоздания Activity.
8. Поднять настоящую экранную клавиатуру, ввести кириллицу и многострочный текст: поле и отправка должны быть видимы выше клавиатуры. Back скрывает клавиатуру и сохраняет черновик. Переход в историю/настройки скрывает клавиатуру. В поиске IME-кнопка «Поиск» закрывает её.

## Прогон облачной версии 1.1

Первый запуск Android-теста выявил неработающий DNS эмулятора (не определялся даже google.com). Эмулятор перезапущен с `-dns-server 1.1.1.1,8.8.8.8`, без очистки данных. Повторный прогон успешен: LiveCloudAcceptanceTest (три настоящих ответа и автоматический пейвол), KeyboardTest (настоящая русская IME, многострочный ввод, Back, поиск, переходы), DeleteChatTest и RoomPersistenceTest — 4/4. Квота текущей установки исчерпана реальными успешными ответами, сброса не было. Запись: `docs/ai-chat-cloud.mp4`.

Финальная проверка после замедления печатания и добавления fallback цен: TypewriterTest, PaywallFallbackTest, KeyboardTest, DeleteChatTest, RoomPersistenceTest — 5/5. Тест печатания управляет временем Compose: проверяет отсутствие мгновенного вывода крупного чанка и завершение только после показа текста; это компонентная фикстура, не режим приложения.

Повторная DNS-проблема оказалась связана с сетью эмулятора при работающем VPN на Mac. Для финального UI-прогона только эмулятор подключён через существующий локальный HTTP proxy VPN. В APK настроек прокси нет; адрес backend остаётся публичным HTTPS. Предыдущий живой прогон трёх ответов выполнен через прямое соединение эмулятора.
