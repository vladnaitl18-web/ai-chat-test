# Сборка для телефона

Актуальный APK подключается к Cloudflare по HTTPS. Достаточно интернета; локальный компьютер и общая Wi-Fi сеть не нужны.

```sh
./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Обновление поверх установленного приложения сохраняет Room, device_id и остаток лимита. Удаление приложения/очистка данных создаёт новую установку и новый UUID; сервер выдаёт ей 3 сообщения. Это не защита от злоупотребления переустановками.

При миграции с локального Node backend на Cloudflare аккаунт создаётся в новом хранилище; прежний локальный лимит автоматически не переносится. Настройка backend: [cloud.md](cloud.md).
