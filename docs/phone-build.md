# Сборка для телефона

Актуальный APK подключается к Cloudflare по HTTPS. Достаточно интернета; локальный компьютер и общая Wi-Fi сеть не нужны.

```sh
./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Обновление поверх установленного приложения сохраняет Room и остаток лимита. Начиная с 1.2 device_id — хеш ANDROID_ID: при обычной переустановке APK с той же подписью лимит сохраняется на сервере. Старый UUID привязывается при первом запуске обновления с помощью существующего refresh token. Удаление старой версии до такого обновления не позволяет перенести её лимит. Другой профиль Android, другая подпись и сброс устройства меняют идентификатор; полноценный антифрод не заявляется.

При миграции с локального Node backend на Cloudflare аккаунт создаётся в новом хранилище; прежний локальный лимит автоматически не переносится. Настройка backend: [cloud.md](cloud.md).
